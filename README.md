# 📖 Introduction

Pandas is an open-source Python library used for data analysis and data manipulation. It provides powerful and flexible data structures that make working with structured data easy and efficient.

Pandas is mainly used for:

Data cleaning

Data transformation

Data visualization preparation

Statistical analysis

Handling CSV and Excel files

It is one of the most important libraries in Data Science and Machine Learning.

# 📚 Core Concepts Covered
1️⃣ Series

A one-dimensional labeled array capable of holding any data type.

2️⃣ DataFrame

A two-dimensional labeled data structure with rows and columns, similar to an Excel sheet or database table.

3️⃣ Data Operations

Indexing and slicing

Filtering data

Sorting values

Adding and deleting columns

Handling missing values

4️⃣ File Handling

Reading CSV files (read_csv())

Reading Excel files (read_excel())

Writing data to files

5️⃣ Data Analysis Functions

mean()

median()

mode()

sum()

describe()

groupby()
